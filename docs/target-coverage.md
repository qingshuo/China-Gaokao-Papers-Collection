# 卷制目标与缺口

本页由 `python3 scripts/target_coverage.py --write docs/target-coverage.md` 自动生成。
每项是一个实际可区分的考试卷制（年份、卷种、学科和使用范围），可关联多个文件版本。这里的覆盖率只针对 `data/paper-targets.csv` 中已明确声明的目标，**不能**代表全国所有高考试卷的完成率。

## 已声明目标的覆盖情况

- 已声明目标：**36**
- 有官方身份佐证：**36**
- 已入库完整卷：**33**
- 仅外部定位：**1**
- 待收录：**2**
