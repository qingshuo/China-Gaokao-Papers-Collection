# 收集与核验计划

项目的长期目标是建立尽量完整、准确、目录清晰且可多维检索的中国高考试卷库。这里的“完整”定义为：在明确的年份、卷种、学科范围内，所有已经发现且可合法引用或托管的公开版本都有可追溯记录；不把未公开或授权不明的资料误称为缺失或可自由再发布。

## 收集范围与阶段

当前优先范围是 2017 年至今的全国卷、新高考卷、各省自主命题卷和浙江分次选考；在近年范围稳定后，再向 1977 年起的历史资料回溯。答案、解析与片段资料保留为辅助档案，不计入完整试卷数量。

## 官方入口

[`data/official-portals.csv`](../data/official-portals.csv) 登记教育部教育考试院及 31 个省级考试机构的入口。入口仅表示优先核查渠道，**不表示该网站一定提供试卷下载，也不表示文件已获再发布许可**。每次访问后应把对应记录更新为已访问、可下载、仅公告或失效，并在 `data/sources.csv` 与试卷记录中保留具体页面链接。

## 文件入库标准

1. 确认试卷身份：年份、使用范围/卷种、考试批次、学科必须可区分。
2. 优先顺序：官方公开发布或明确授权来源 > 可追溯的公开存档 > 未核验的线索。
3. 同一试卷的多格式副本只保留优先格式：PDF > DOCX > DOC > TEX；答案和原卷分别作为不同资料类别处理。
4. 本地文件必须记录来源、SHA-256、许可状态和核验说明；无法合法托管的资料只保留外部链接和元数据。
5. 每次导入都执行哈希去重、内容/页数抽查和目录分类；普通练习、模拟卷、片段题和推广文件不进入主试卷库。

## 覆盖率的口径

覆盖率只在“目标清单”建立后计算。目标项的身份由 `年份 + 使用范围/卷种 + 考试批次 + 学科` 组成，不按文件数计算；一个全国卷覆盖多个省份时只算一个目标项。当前 [覆盖统计](coverage.md) 展示的是已收录文件数，不应解读为全国完整率。

## 持续工作流

1. 逐省访问官方入口，登记具体公告或下载页，并建立目标项。
2. 对每个目标项查找官方文件或有明确授权的镜像；记录来源等级和授权状态。
3. 下载前检查是否已经存在同一试卷；导入后优先保留 PDF 并进行哈希和内容核验。
4. 生成按年份、地区和学科的索引，公布已收录、待核验和缺失目标。
5. 收到权利人通知时，撤下本地副本，保留撤回记录和来源说明。

每次补库前先查看 [来源可追溯性审计](traceability.md)：优先为“仅本地导入来源”的记录补具体公开出处，再决定是否保留镜像文件。

## 如何贡献

请优先提交具体的官方公告页、可公开访问的原文件链接或明确许可依据，而不是泛泛的搜索页。提交时应说明试卷身份、是否完整、是否包含答案/解析，以及能否重新分发。详见 [贡献指南](../CONTRIBUTING.md)。
