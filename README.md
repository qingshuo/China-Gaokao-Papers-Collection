## 目录结构

试卷文件统一放在 `papers/<年份>/<地区>/<学科>/`；PDF 可直接在线预览，DOCX/DOC 适合继续编辑。每份文件的来源、SHA-256、格式和授权状态记录在 [`data/exams.csv`](data/exams.csv)。

本仓库只记录当前收集到的资料，不代表试卷全集。资料授权状态默认标记为“待核验”，使用和再分发前请查看 [第三方资料归属](THIRD-PARTY-NOTICES.md)。
